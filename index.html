Cloud Database Setup Required for GitHub Pages

The app is currently in Local Fallback Mode because it was blocked by your Firebase settings. Games will vanish on refresh until you fix this. To enable persistent global storage on GitHub Pages:

  • Enable Auth: Go to Firebase Console > Authentication > Sign-in method > Enable Anonymous.
  • Authorize Domain: Go to Authentication > Settings > Authorized domains > Add github.io (or your custom domain).
  • Open Rules: Go to Firestore Database > Rules and paste this exactly:
    match /{document=**} { allow read, write: if true; }

Once completed, refresh the page to connect securely to your global database!
